# RobiDuo

URDF model, chassis driver, and arm firmware for RobiDuo.

## Robot description

[Download the RobiDuo URDF archive](RobiDuo_ros2.zip).

`RobiDuo_ros2.zip` contains the RobiDuo URDF robot description.

## Chassis driver

[Download the chassis driver V1.1.3](chassis_driver/dt_control_ros_V1.1.3.zip).

The driver uses **ROS 1 / catkin** and includes:

- `dt_control`: chassis communication and control node.
- `dt_control_msgs`: chassis message definitions.

Extract the archive to access the source code, launch file, and usage documentation.
